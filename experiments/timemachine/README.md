# 프로토타입: 타임머신 대조 화면

> **상태: 1회성 프로토타입, 프로덕션 코드 아님.** M0/M2 착수 시 버리고 정식 구현으로 교체한다.
> 존재 이유는 하나 — `docs/DESIGN-DRAFT.md` §7의 화면 설계를 **상상이 아니라 실물로 확정**하기 위함.

초판 §7은 실물 없이 썼고, 그래서 도구가 아니라 대시보드가 나왔다. 조문을 읽을 수조차 없는
목록에 큰 숫자 타일과 필터 칩을 얹은 형태였다. 이 프로토타입을 만들며 §7을 다시 썼다.

## 파일

| 파일 | 내용 |
|---|---|
| `articles_full.tsv` | 실제 「민간건설공사 표준도급계약서」 일반조건에서 추출한 43개 조 (조번호·제목·본문) |
| `gen_rounds.py` | 위 조문에 협상 4회차를 합성하고, **실제 정렬 알고리즘을 돌려** `rounds.json` 생성 |
| `rounds.json` | 회차 4개 + 비교쌍 4개(정렬결과·어절diff·정확도) + 조항 계보 |
| `build.py` | `rounds.json`을 단일 HTML로 묶음 |
| `screenshot_dark.png` / `screenshot_light.png` | 실행 화면 |

```bash
python3 gen_rounds.py && python3 build.py   # → timemachine.html
```

## 데이터의 성격 — 어디까지가 진짜인가

- **진짜**: 43개 조의 조문 원문 (국가법령정보센터 공개 문서)
- **진짜**: 정렬 결과. `gen_rounds.py`가 §3.1 알고리즘(앵커 + `0.4·제목 + 0.5·본문 + 0.1·번호근접`)을
  실제로 돌려 계산한다. 화면의 매칭·신뢰도는 하드코딩이 아니다.
- **합성**: 협상 4회차(원안 → 시공사 1차 → 발주처 검토 → 최종). 실제 시공사 redline은 비공개
  문서라 구할 수 없어, 정비사업 실무에서 실제로 벌어지는 수법을 본떠 만들었다:
  - 1차: 물가변동 특례 신설(임계치 없는 "조정하지 아니한다"), 손해의 부담 조항 삭제,
    원자재 연동 기준 10%→20% 완화, `응하여야 한다`→`응할 수 있다` 의무 완화
  - 2차: 건설공사비지수 누적변동률 15% 임계치 삽입, 삭제 조항 복원, 기준 15% 환원, 의무 복원
  - 최종: 임계치 12%로 강화, 품질미이행 LD(1000분의 5) 신설

## 정렬 정확도 — 실측

각 회차 쌍에서 알고리즘의 정렬 결과를 조항 uid 정답과 대조한 값이다.

| 회차 | 정확도 | 비고 |
|---|---|---|
| 원안 → 1차 | **39 / 42** | 조항 삭제 + 번호 밀림이 겹친 가장 어려운 라운드. **3건 오정렬** |
| 1차 → 2차 | 43 / 43 | |
| 2차 → 최종 | 44 / 44 | |
| 원안 → 최종 | 43 / 43 | |

3건 오정렬은 숨기지 않고 화면 상단(`정렬 39/42 · 검수필요 3`)과 해당 행 거터에 노란 표시로
드러낸다. 설계 근거는 §7.4.

## 이 프로토타입이 §7에 확정시킨 것

1. **좌우를 3열 그리드 한 개로 그린다** (§7.0) — 행 높이 정렬·스크롤 동기화·좌우 동시
   하이라이트 세 문제가 한꺼번에 사라진다. 별도 패널 방식이었다면 전부 JS로 방어해야 한다.
2. **hover가 주 조작** (§7.1) — 검토자는 자를 대고 훑지, 한 건씩 열어보지 않는다.
3. **동일 구간 접기** (§7.2) — 체감 차이가 가장 컸다. 넣기 전에는 `응하여야 한다 → 응할 수 있다`
   변경을 보려면 한참 스크롤해야 했고, 넣은 뒤에는 첫 화면에 바로 보였다.
4. **정렬 신뢰도 상시 노출** (§7.4)

## 구현자가 반드시 알아야 할 함정

프로토타입에서 실제로 겪은 버그다.

- **행 인덱스를 `자식위치 / 3`으로 계산하지 말 것.** 접힘 밴드는 그리드 자식을 1개만 차지하므로
  산술이 깨지고, 트래킹이 엉뚱한 조를 가리킨다. 각 셀에 `data-row`를 박고 그것으로 찾는다.
- 하이픈이 들어간 id(`hl-nm`)를 암묵적 전역으로 참조하면 안 된다. 렌더 함수가 통째로 죽는다.
- 조문 본문은 클램프 필수. 안 하면 조문 하나가 화면 절반을 먹어 훑기가 불가능하다.

## 한계

실제 신탁사 정비사업 도급계약서가 아니라 일반 민간건설 표준계약서이고, 회차도 합성이다.
정비사업 특유 조항(공사비 검증, 정비사업지원기구)은 여기 없다. 표(表) 처리는 테스트조차 안 됐다.
**회사 실제 계약서가 확보되면 §10의 M1 게이트에서 반드시 재검증한다.**
