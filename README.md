# diffcheck

정비사업 도급계약서 대조 검토 도구 (로컬 웹앱).

두 개 이상의 계약서를 **조항 단위로 정렬·대조**하고, 결과를 **전/후 대비표 Word 문서**로 내보낸다.

> 현재 상태: **설계 초안 단계.** 구현 코드 없음.
> 설계 문서 → [`docs/DESIGN-DRAFT.md`](docs/DESIGN-DRAFT.md)

## 지원 예정 비교 모드

- A. 원본 vs 우리 수정안 → 전/후 대비표 생성
- B. 표준계약서 vs 시공사 제출본 → 독소조항 탐지
- C. 협상 라운드 간 버전 비교
- D. 과거 사업 계약서 간 문구 일관성 점검

## 지원 예정 포맷

HWPX · DOCX (1순위) / HWP · PDF (후순위, 신뢰도 표시)
